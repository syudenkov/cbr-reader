lets create a promt for the claude for the following project: it will be a CBR, CBZ files (comics, диафильмы) viewer that will be hosted somewhere and will allow to view files in a fullscreen mode page by page or in a scrolling mode. It will remember positions of the files, allow to rate the files, allow to analyze the script on each page and create audio to be played on each page (this feature should be on demand - user requests TTS processing - and system involves LLM to OCR file and prepare JSON with speakers to create proper audio for each page, this processing results must be stored along with the files). Admin part will be quite  simple - user management, files management, logs, audit logs, LLM configuration (OpenAI API + Claude API for OCR, Minimax API (https://www.minimax.io/) for TTS). Backend will be Java21, Spring Boot 4, SQLLite - files will be stored on a disk for the first approach. Frontend part will be on React 18 + MUI components. Use context7 mcp server to find out all the best practices for the mentioned libraries and the architecture in general.
